# Tidy

A Chrome extension that tracks your work hours and reminds you to take breaks.

## Features

- **Session timer** — start, pause, and resume work sessions from the toolbar popup.
- **Break reminders** — get reminded to take a break after a configurable focus interval.
- **Repeat reminders** — optionally keep getting reminders at each interval until you resume working.
- **Daily goal** — set a target (e.g. 4 hrs/day) and see a live progress bar.
- **Statistics** — view daily and weekly focus time, comparisons, and a bar chart of the last 7 days.
- **Toolbar badge** — see your elapsed time while a session is running.
- **Backup & restore** — export all your data as JSON and import it back, choosing what to restore.
- **Browser-restart safe** — if Chrome closes mid-session, the elapsed time is recorded on next startup.

Everything is configurable in the extension's settings page.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
5. Pin Tidy to the toolbar.

## Built with

- Vanilla HTML, CSS, and JavaScript (no frameworks)
- [Web Awesome](https://webawesome.com/) (Awesome theme, curated local vendor — see [VENDOR.md](VENDOR.md))
- [Instrument Sans](https://fonts.google.com/specimen/Instrument+Sans) variable font (self-hosted)
- Chrome Extension Manifest V3 (service worker, alarms, notifications, offscreen documents)

## Vendored Web Awesome

Tidy does not ship the complete Web Awesome browser distribution. A script
(`tools/vendor-webawesome.mjs`) pins the exact version and vendors only the
runtime dependency graph the 7 components Tidy uses actually need — so the
extension stays fully self-contained at runtime: no CDN, no remote JS, CSS,
or fonts, and no unused package content.

The generated vendor is committed so clones and `chrome://extensions` installs
work with no build step and no internet. It must never be edited by hand —
`npm run vendor:webawesome` regenerates it, and `npm run vendor:webawesome --
--check` verifies a clone is intact. See [VENDOR.md](VENDOR.md) for the
complete maintenance process (adding, removing, and upgrading components).

| Area | Before: full Web Awesome | After: curated vendor |
| --- | --- | --- |
| Vendor size | ~11 MB | ~532 KB |
| Runtime files | 1,189 | 105 |
| Components shipped | 73 (entire package) | 7 (only what Tidy uses) |
| Unused package content | included | excluded |
| Runtime network requirement | none, but unnecessary content shipped | none |
| Dependency management | carry the whole distribution | resolved runtime closure |
| Adding a component | copy/update package contents | add it and regenerate |
| Reproducibility | package contents committed by hand | pinned version + manifest + hashes |
| Maintenance | manually carrying the full package | generated by `npm run vendor:webawesome` |

## Privacy

Tidy has no analytics and makes no network requests. All data (settings and session history) is stored locally in `chrome.storage.local` and never leaves your device. Backups are files you create and import yourself.
